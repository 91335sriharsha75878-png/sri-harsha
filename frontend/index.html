Comparison: Frontend vs Backend Responsibilities

Responsibility Dimension Frontend Layer (Browser) Backend Layer (Node.js Express)
API Key & Secrets ❌ Never stored or exposed in client bundles ✅ Secured in server environment (.env)
User Experience ✅ Real-time typing, Markdown, copy buttons, modals ❌ Headless, no presentation logic
LLM Communication Calls internal /api/chat endpoint Calls Google Gemini API using @google/genai
Data Streaming Listens to SSE stream & renders tokens dynamically Streams chunks to client as Gemini generates them
Error Handling Displays friendly toast & retry actions Normalizes API quotas, invalid keys, and rate limits
